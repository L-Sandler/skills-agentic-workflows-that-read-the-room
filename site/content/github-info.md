## Recent updates
- **Require proof of presence for high-impact actions**: GitHub now requires proof of presence for sensitive actions, improving account security ([GitHub Changelog](https://github.blog/changelog/2026-09-24-require-proof-of-presence-for-high-impact-actions)).
- **Rendering huge pull requests in the GitHub Copilot app**: The Copilot app can now open million-line pull requests with hundreds of comments efficiently ([GitHub Blog](https://github.blog/engineering/user-experience/rendering-huge-pull-requests-in-the-github-copilot-app/)).
- **OpenTelemetry in the GitHub Copilot app**: The Copilot app now supports OpenTelemetry for enhanced observability ([GitHub Changelog](https://github.blog/changelog/2026-09-22-opentelemetry-in-the-github-copilot-app)).
- **OSPO Org Health workflow**: Weekly health reports for organizations, surfacing stale issues/PRs and contributor leaderboards ([Awesome Copilot](https://github.com/github/awesome-copilot/blob/main/workflows/ospo-org-health.md)).
